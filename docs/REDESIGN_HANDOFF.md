## 2. デザインの決まり（トークン）

### 色

| 用途 | ライト | ダーク（ライト基調） |
|---|---|---|
| 背景 `--u-bg` | `#F7F1E8`（クリーム） | `#17151B` |
| カード `--u-surface` | `#FFFFFF` | `#24212A` |
| 少し濃い面 `--u-chip`/`--u-soft` | `#EFE6D8` | `#2C2832` |
| 文字 `--u-ink` | `#1A1714` | `#F5EFE6` |
| 薄い文字 `--u-sub` | `#6B6257` | `#A79E92` |
| 線 `--u-line` | `#E4DACB` | `#3A3540` |
| アクセント `--u-accent` | `#FF5A1F`（オレンジ） | `#FF5A1F` |
| ポップ `--pop` | `#FFD23F`（黄） | `#FFD23F` |
| 太枠・ずらした影の色 | `#1A1714` | `#000000` |
| 細い枠（ラベルの外枠・進み具合バーの枠） | `#1A1714` | `#8C8496` |
| レール・ドック・黒いボタンの地 | `#1A1714` | `#0B0A0E` |
| レール・ドックの選択中 | 黄 `#FFD23F`＋黒文字 | 同じ |
| 視聴済みのシール | `#3DDC97` | 同じ |

- 黄・緑の上の文字は、ダークでも黒（`#1A1714`）のまま。
- `--u-on`（アクセントの上の文字）は白。

### 形（ステッカー）

- カード：`border:2px solid 枠色; border-radius:18px; box-shadow:4px 4px 0 枠色`
- 小さいボタン・札：`border:2px solid 枠色; box-shadow:2px 2px 0 枠色`
- 主ボタン（追加など）：アクセント地＋太枠＋影
- ポスター：太枠＋影、少し傾ける（-3°〜+1.5°。グリッドは1枚ずつ角度を変える）
- 視聴ステータスはポスターの左上に**斜めに貼ったシール**（視聴中＝黄、未視聴＝白、視聴済み＝緑）
- 進み具合バー：太さ8〜10px、細い枠付き、中身はアクセント
- 大きな数字（％・未視聴数・時刻など）は Rubik 800〜900、アクセント色

### 書体（index.html で読み込み済み）

- 見出し：`Mochiy Pop One`（`--fd`）。太さは400のみ（`font-weight:400` で使う。700にすると疑似太字になる）
- 数字：`Rubik` 800/900（`--fn`）
- 本文：`Zen Kaku Gothic New`（`--u-f`）
- `Dela Gothic One`・`Bebas Neue` はシアター版用だったので、使わなくなったら読み込みから外してよい

## 3. メニュー構成（新）

| 新メニュー | 中身 | 今のコード上の mode |
|---|---|---|
| 今夜 | 番組表 | `w` |
| ライブラリ | 上の大きな文字のタブで アニメ／ドラマ／映画／バラエティ／YouTube を切り替え | `a` `d` `m` `s` `yt` |
| コレクション | シリーズ・主題歌（タブ切り替え） | `sr` `mu` |
| 設定 | 今の設定画面 | （`data-gear`） |

- 視聴記録は削除済みなので「わたし」ではなく「設定」。
- 「その他」画面（`renderOther` のタイル）は不要になる。
- **PC**：左の文字メニュー（`renderSidebar`、`#sb`）をやめ、**幅88pxの細いアイコンの縦レール**にする。上からロゴ→大きな「＋」（追加）→今夜／ライブラリ／コレクション→下端に設定と保存状態。レールの地は黒、選択中は黄色の角丸＋黒文字。
- **スマホ**：下メニュー（`renderBnav`、`#bnav`）を、**画面から浮いたドック**にする（左右14px・下14px・高さ64px・角丸22px、地は黒、ライトはオレンジのずらした影）。並びは 今夜／ライブラリ／**真ん中に大きな「＋」（少し上に飛び出す・オレンジ地・太枠）**／コレクション／設定。上の帯（`header .hbar`）は小さなロゴと検索だけにし、今の右上の＋・⚙は外す。
- ライブラリのジャンル切り替えは、画面上部に「アニメ 128」のように**選択中だけ大きく（スマホ30px／PC40px・Mochiy）、他は小さい太字**で横並び。件数はアクセント色の数字。
- 今の `state.mode` の仕組みはそのまま使い、メニューの見せ方だけ変えるのが安全（ライブラリ内タブ＝a/d/m/s/yt の切り替え、コレクション内タブ＝sr/mu）。

## 4. 画面ごとの仕様

### 今夜（番組表）

- 上：小さく「TONIGHT」（アクセント・字間広め）＋大きく「今夜の番組表」（Mochiy）。右に大きな数字（未視聴の話数）。
  - PCは右に「未視聴 4話／今週見た 12話／連続 5日」の札を3つ（今週見た・連続日数は今のデータで出せるか確認。出せないものは出さない）
- 曜日：7つの角丸ボタン（白地・太枠、今日はアクセント地＋白文字＋影）。放送のある日は小さな点。
- その日のタイムライン：左に時刻（Rubik 900）、右にカード（白・太枠・影）。カードの中に小さなポスター（太枠）・ジャンル／配信サイトのラベル・タイトル（Mochiy）・「7話『サブタイトル』」・進み具合バー・「○話を見た」ボタン（黄地・太枠）。カードの右上に斜めのシール（ON AIR／NEXT／見た）。
- 今の時刻の位置に「NOW 22:41」の札と横線（アクセント）。
- 今の時計＋未視聴の箱（`.wtop`）は、上の見出しに置き換える（時計は不要。必要なら小さく）。
- **PCだけ**：右の列（幅380px）に
  - 「NEXT UP」：次に放送する作品を大きなポスターで。「あと1時間49分」・タイトル・話数・「Netflixで見る」「7話を見た」
  - 「未視聴がたまっている作品」：小さなポスター＋タイトル＋未視聴の数の行を数件
- 関係するコード：`view.js` の `renderWeek` / `weekCard` / `weekTopHtml` / `weekDayTabs`

### ライブラリ（アニメなどの一覧）

- 上：小さく「ライブラリ」→ジャンルの大きな文字タブ→道具の行（「絞り込み 2」は黒地の札、状態の札〔すべて・視聴中…〕、右端に検索・並び替え・表示切替の四角いボタン）。
- **最初からポスターのグリッド**（スマホ2列、PC5列）。ポスターは太枠＋影＋少し傾け、左上に斜めのステータスシール。下にタイトル（Mochiy）と進み具合バー＋「6/12」。
- 今のリスト表示・グリッド表示の切り替え（`data-lview`）は残してよいが、既定をグリッドに。
- **PCは詳細を右側に開いたまま**（幅470px、左に太枠の境目）。一覧で選んでいる作品はオレンジの影＋外側のオレンジ線で目立たせる。前・次の作品の矢印・編集・閉じるは詳細の右上。今のモーダル（`#layer .sheet`）をPCだけ右の固定パネルにする形。
- 関係するコード：`view.js`（一覧描画・`renderSidebar`・`renderBnav`・`renderOther`）、`filters.js`（絞り込み・並び替え）、`img.js`（`gridCell` 等）

### 番組詳細

- スマホ：上の段（ジャンル・ステータス・前後・編集・✕）は上に固定。その下に大きな見出し：傾けたポスター（太枠＋影）＋右に大きな「50%」と「6 / 12話 見た」と太いバー。右上に黄色の大きな丸の飾り。タイトル（Mochiy 24px）、ラベル、「Netflixで見る」（黒地・オレンジの影）「公式サイト」（白地・太枠）。
- タブ「番組情報／話数 6/12」は上の段のすぐ下に固定（選択中は黄地＋太枠＋影）。
- 番組情報タブの一番上に「次に見る」を1行（オレンジの札「次に見る」＋「7話『…』」＋右端に「見た」）。大きくしない。
- ON AIR・MUSIC などのカードは白地＋太枠、見出しはアクセント色・Rubik・字間広め。
- 話数リスト：見た話の丸はオレンジ地＋太枠、次の話は黄地＋淡い黄色の背景。話数の数字は Rubik。
- PC：右の固定パネル（上記）。ライトは傾けたポスター＋％、タイトル、ラベル、ボタン、タブ、次に見る、カード。
